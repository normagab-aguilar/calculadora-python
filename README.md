# Calculadora en Python 
Calculadora de consola que permite realizar las operaciones basicas: suma, resta, multiplicacion y division. El usuario ingresa dos numeros y elige la operacion desde un menu interactivo. 
## Como ejecutarla
1. Clonar este repositorio 2. Abrir una terminal dentro de la carpeta del proyecto 3. Ejecutar: python calculadora.py 4. Seguir las instrucciones del menu en pantalla
