# Calculadora en Python Calculadora de consola que permite realizar las operaciones basicas: suma, resta, multiplicacion y division. El usuario ingresa dos numeros y elige la operacion desde un menu interactivo. 
## Como ejecutarla 1. Clona este repositorio 2. Abri una terminal dentro de la carpeta del proyecto 3. Ejecuta: python calculadora.py 4. Segui las instrucciones del menu en pantalla
